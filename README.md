# 基于 SpringBoot + Vue 的料理技巧分享平台 (Cooking Skills Sharing Platform)

生鲜百科 · 技巧贴子 · 互动留言 · 消息通知 · 用户关注 · 敏感词过滤 · 多模块管理 · 社区化运营

本项目是一套面向美食爱好者与烹饪从业者的料理技巧分享社区平台，采用前后端分离架构，覆盖**管理员**与**普通用户**两类角色。系统围绕"生鲜百科、技巧贴子、留言互动、消息通知、用户关注、敏感词过滤、模块管理"等核心业务设计，支持图文/视频内容发布、多级评论回复、贴子收藏点赞、用户关注订阅、生鲜食材知识库、实时消息通知、内容审核与敏感词过滤，实现从内容创作、社区互动到知识沉淀的全流程闭环，适用于美食社区运营、烹饪教学平台、生鲜电商内容社区、餐饮行业知识分享等场景。

## 核心特性

- **技巧贴子发布**：用户可发布料理技巧贴子，支持富文本编辑（图文混排）、视频嵌入、标签分类（如刀工技巧、火候控制、调味秘籍、摆盘艺术）、封面图上传，贴子支持草稿保存与定时发布。
- **多级评论回复**：支持贴子留言与多级嵌套回复，用户可对贴子或他人评论进行回复，形成讨论楼层，支持评论点赞与举报。
- **用户关注订阅**：用户可关注感兴趣的创作者，关注后在首页信息流中优先展示其新发布贴子，支持粉丝列表与关注列表查看。
- **贴子收藏与点赞**：用户可收藏优质贴子至个人收藏夹，支持贴子点赞统计，热门贴子按点赞/收藏/评论数排序展示。
- **消息通知系统**：实时推送消息通知，包括被回复通知、被点赞通知、被关注通知、系统公告、审核结果通知，支持已读/未读状态管理。
- **敏感词过滤**：内置敏感词库，对用户发布的贴子、评论、留言进行实时过滤与自动审核，命中敏感词的内容自动拦截并标记待审，保障社区内容合规。
- **内容审核与管理**：管理员可对贴子、评论进行审核（通过/驳回/删除），支持举报内容处理、违规用户封禁、内容置顶/加精操作。
- **首页个性化推荐**：首页展示推荐贴子、热门贴子、关注用户动态、生鲜百科精选，支持按标签/分类筛选，算法可根据用户浏览历史与关注关系进行个性化排序。

## 功能模块概览

## 管理员端

管理员拥有平台最高权限，负责内容审核、用户管理与平台运营：

### 基础管理

- **用户管理**：查看平台所有注册用户，包括用户名、昵称、头像、注册时间、粉丝数、贴子数、账户状态，支持用户封禁/解封、违规记录查看、用户角色调整。
- **模块管理**：管理平台功能模块配置，包括贴子分类标签、生鲜百科分类、首页推荐位、热门话题等，支持模块启用/禁用与排序调整。
- **公告管理**：发布平台公告，包括活动通知、规则变更、系统维护、精选内容推荐等，支持置顶、定时发布、富文本编辑。
- **敏感词管理**：管理敏感词库，包括添加/删除/编辑敏感词，设置敏感词等级（禁止发布/待审核/替换），支持批量导入敏感词，敏感词命中后自动触发内容审核流程。

### 内容与互动管理

- **生鲜百科管理**：维护生鲜食材知识库，包括食材名称、分类、图片、营养信息、储存方法、挑选技巧、烹饪建议，支持百科词条的新增、编辑、删除与审核。
- **贴子管理**：查看平台所有贴子，包括贴子标题、作者、发布时间、浏览量、点赞数、评论数、贴子状态（已发布/待审核/已驳回/已删除），支持贴子审核、置顶、加精、推荐至首页、批量删除。
- **留言板管理**：查看与管理用户发布的留言/评论，支持按贴子/用户筛选，支持评论删除、举报处理、违规评论批量清理。
- **消息管理**：查看平台消息发送记录，包括系统消息、审核通知、活动推送等，支持消息模板管理与批量推送。
- **消息回复**：处理用户通过留言板或反馈渠道提交的问题与建议，管理员可回复用户消息，形成客服工单式交互。
- **首页管理**：配置首页展示内容，包括轮播图、推荐贴子、热门话题、生鲜百科精选、活动Banner等，支持拖拽排序与上下架控制。

### 统计看板

- **内容统计**：展示贴子总数、日新增贴子数、评论总数、活跃用户数等核心指标。
- **用户统计**：展示注册用户趋势、日活跃用户、新增关注关系数、用户留存率。
- **热门内容**：展示热门贴子TOP10（按点赞/评论/收藏综合排序）、热门搜索词、热门标签。
- **审核统计**：展示待审核内容数量、审核通过率、敏感词命中次数、违规用户数。

## 用户端

普通用户为平台内容创作者与社区参与者，提供完整的内容发布与社交互动功能：

### 账号与个人

- **用户登录注册**：支持手机号+验证码注册登录、账号密码登录、第三方登录（微信/QQ），支持找回密码、个人信息编辑（昵称、头像、简介、擅长菜系）。
- **个人主页**：展示个人发布的贴子、收藏的贴子、粉丝数、关注数、获赞数，支持编辑个人资料与隐私设置。

### 内容创作

- **发布贴子**：用户可发布料理技巧贴子，支持富文本编辑器（图文混排）、视频上传/嵌入、添加标签（如#刀工技巧 #家常菜谱 #烘焙入门）、设置封面图、选择分类，支持保存草稿与定时发布。
- **发布留言/评论**：在贴子详情页发布评论，支持对其他用户的评论进行回复，形成多级讨论楼，支持评论点赞。
- **贴子回复**：对他人贴子或评论进行回复，支持@提及用户，被@用户收到消息通知。

### 社交互动

- **贴子收藏**：将喜欢的贴子加入收藏夹，支持创建多个收藏夹分类（如"烘焙技巧""川菜秘籍"），方便后续查阅。
- **用户关注**：关注感兴趣的创作者，关注后在其发布新贴子时收到消息通知，支持取消关注与查看关注/粉丝列表。
- **消息通知**：实时接收消息通知，包括被回复、被点赞、被关注、系统公告、贴子审核结果等，支持一键全部已读与通知偏好设置。

### 浏览与搜索

- **首页浏览**：首页展示推荐贴子流、热门贴子、关注用户动态、生鲜百科精选，支持下拉刷新与无限滚动加载。
- **生鲜百科**：浏览生鲜食材知识库，支持按分类（蔬菜/肉类/海鲜/水果）筛选、关键词搜索，查看食材详细信息与关联贴子推荐。
- **搜索功能**：支持按贴子标题/内容/标签/作者进行搜索，支持按时间/热度排序，搜索结果高亮显示匹配关键词。
